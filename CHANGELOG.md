# Changelog

All notable changes to **Astra Navi Desktop** are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- **VRM 1.0 & Verlet Spring-Bone Physics (`src/shared/vrm.ts`, `src/renderer/src/vrmLoader.ts`):** Pure TypeScript glTF 2.0 / VRM 1.0 (plus VRM 0.x fallback) binary parser and Babylon.js loader with standardized humanoid bones, lip-sync/expression visemes, sphere/capsule collider Verlet spring-bone physics, and expanded procedural/conversational gestures.
- **Native Model Context Protocol (MCP) Client (`src/core/mcpClient.ts`, `src/core/semanticBridge.ts`):** JSON-RPC 2.0 client over stdio subprocesses and Streamable HTTP/SSE transports with `McpHub` (`mcp:<server>.<tool>` namespacing), `McpSemanticBridge`, and `core/permissions.ts` gating.
- **Bundled Creator Plugins & Creator Pack Distribution (`plugins/`, `src/core/pluginSdk.ts`, `src/core/workshop.ts`):** Optional Ed25519/SHA-256 verified **Coding Companion Mode** (`plugins/coding-companion`) and **OBS & Twitch Co-Host** (`plugins/obs-cohost`) plugin packs (`defaultEnabled: false`), plus signed HTTPS creator catalogs (`CreatorCatalogSchema`) and Steam Workshop discovery scaffolding.
- **Zero-Python Embedded ONNX Voice (`src/core/voice/onnxVoice.ts`):** Built-in CPU neural TTS powered by `kokoro-js` (`onnx-community/Kokoro-82M-v1.0-ONNX`) across English, Japanese, and Chinese presets without requiring Python or PyTorch.
- **Mobile Station QR + mDNS Pairing & Profile Backups (`src/core/qrCode.ts`, `src/core/mdns.ts`, `src/core/profileBackup.ts`):** Zero-dependency ISO/IEC 18004 QR code pairing URIs, `_astranavi._tcp.local` LAN mDNS responder, Android NSD discovery (`phone-app/`), and atomic gzipped SHA-256 verified profile export/import (`*.anprof`).
- **Three Bundled Mascot Variants (`assets/models/variants/`):** `astral-midnight`, `sakura-nebula`, and `solar-dawn` signed bundle source folders.
- **Spatial Stage & Opt-In Presence (`src/shared/spatialStage.ts`, `src/renderer/src/stage.ts`, `src/main/index.ts`):** Multi-monitor edge docking, procedural 3D room scenes (`cozy-desk`, `command-bridge`, `minimal-studio`), circadian + screen-ambient lighting, and opt-in local webcam presence/gaze tracking (off by default).
- **Duplex Speech-to-Speech & Continuous Vision (`src/core/multimodal.ts`):** `DuplexSpeechToSpeechPipeline` (pre-roll ring buffer, VAD endpointing, instant barge-in abort) and `ContinuousVisionStreamer` (adaptive FPS block-delta detection, live coaching cues, privacy/hands-off frame drops).
- **Grammar-Constrained Tool Decoding & Loop Guards (`src/core/grammarGuard.ts`, `src/core/brain.ts`, `src/core/toolRouter.ts`):** Recursive JSON schema hardening (`additionalProperties: false`), llama.cpp GBNF grammar compiler, streaming JSON parameter degeneration abort (`StreamingJsonParamGuard`), and per-turn deterministic `ToolLoopGuard` with full trace redaction.
- **Rolling Model Catalog & Benchmark Habit (`src/core/models.ts`, `scripts/benchmark-catalog.ts`):** One-click preset resolution (`qwen3.5-4b`, `qwen3.5-9b`, `qwen3.8-27b`, plus `pending_gpu` workstation `qwen3-30b-a3b-moe`, `qwen3.5-72b`, `qwen3.5-120b-a16b-moe` entries) and automated `BENCHMARKS.md` Section 6 generation.
- **Release Automation & Code Signing:** Tag-triggered multi-platform release workflow (`.github/workflows/release.yml`), RFC 3161 timestamped Windows Authenticode script (`scripts/sign-windows.ps1`) supporting Azure Artifact Signing / SignPath Foundation / PFX, native multi-resolution `assets/icon.ico`, Chromium & Firefox WebExtension packaging (`npm run package:extension`), and strict external release keystore flow for the Android APK (`scripts/build-android.sh --release`).
- **Clean-Room & Cross-Desktop Reliability:** Graceful non-KDE Wayland (GNOME, Hyprland), X11, and Flatpak detection and fallback notices (`detectLinuxDesktopEnvironment`), Klipper -> `wl-paste`/`wl-copy` -> `xclip` -> `xsel` clipboard fallbacks, blank Windows 11 VM smoke script (`scripts/verify-clean-windows.ps1`), and native Rust `linux-hands` binary (`hands/linux-hands-native/`).

### Security & Hardening
- **Packaged Resource Resolution (`src/core/paths.ts`, `src/main/`, `src/core/hands.ts`, `src/core/platform/windows.ts`, `electron-builder.yml`):** Resolved unpacked `hands/`, `assets/`, `voice-server/`, and `phone-app/` via `process.resourcesPath` (`resolveBundledRoot`) outside `app.asar`, and excluded `*.blend`/`*.blend1`/`*.xcf`/`*.psd` + legacy `win_hands.ps1` from release bundles.
- **7-Boundary Adversarial Audit (`tests/securityBoundariesAudit.test.ts`):** Hardened MCP tool namespacing/SSRF (`::ffff:` hex normalization + `redirect: "error"` + env scrubbing + 2 MiB caps), Workshop/Plugin explicit per-plugin approval + realpath symlink containment, VRM accessor OOM/texture dimension/cycle/NaN guards, ProfileBackup gzip-bomb/Zip-Slip/symlink defenses, QR 64-hex HTTPS pinning & mDNS LAN rate limits, Rust `linux-hands` 64 KiB frame/JSON-depth/`--` flag-injection bounds + RAII input release, and pinned HTTPS GitHub Releases update checks.
- **1080p/60fps Narrated Store Trailer (`scripts/build-store-assets.ts`):** Fixed left-column text layout spacing, added gentle camera motion + Kokoro-82M narration track, and added `--steam-master` high-bitrate export.

## [0.1.0] - Initial Open-Core Release

### Added
- **Original 3D Chibi AI Navigator (`Astra Navi`):** Custom-rigged Babylon.js / MMD desktop companion created in Blender with cel-shaded PBR shaders, eye tracking, blink, idle motion, lip-sync visemes, and encrypted local BYO-MMD `.pmx` bundle support.
- **Local-First LLM Inference & Hardware Auto-Tuner:** On-device GGUF execution (`node-llama-cpp`) across Small (`Qwen3.5 4B`), Standard (`Qwen3.5 9B`), Large (`Qwen3.8 27B`), and Workstation XL (`Qwen3.5 72B`) tiers with automatic VRAM/RAM profiling and game-aware GPU yield.
- **Security Gating & Evaluation Suite:** Explicit confirmation gates, `untrusted` indirect-injection defenses, static rule auditing (`npm run eval -- --audit`), injection fuzzer (`npm run eval -- --fuzz`), prompt budget checks (`npm run prompt-size`), and two-stage tool routing (`npm run route-check`).
- **Native Desktop & Cross-Device Integration:** Persistent NativeAOT `win-hands.exe` UI Automation/SendInput backend on Windows, KWin/AT-SPI integration on KDE Wayland, Qwen3-TTS / Kokoro-82M / Moonshine / Whisper local voice stack, cross-platform dependency bootstrapper (`npm run setup`), Chromium/Firefox semantic DOM Native Messaging extension, SSH Fleet management, and paired Android Station (`app.astranavi.station`).
